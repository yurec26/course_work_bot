# Техническое задание на Курсовое проект по предмету ТРКПО
## SPBSTU Notification Bot - интеллектуальный сервис напоминаний

### 1. Назначение сервиса

**SPBSTU Notification Bot** - сервис для создания и автоматической отправки напоминаний пользователям Telegram с использованием локальной языковой модели (LLM).

Сервис предназначен для пользователей Telegram, в первую очередь студентов, которым необходимо планировать задачи и получать уведомления о предстоящих событиях.

Основная особенность сервиса - возможность создавать напоминания на естественном языке без необходимости заполнять формы или использовать специальные команды.

Например, пользователь может отправить сообщение: «Напомни завтра в 15:00 сдать лабораторную работу».

Локальная LLM обрабатывает запрос, извлекает необходимые параметры и инициирует создание напоминания. В установленное время сервис автоматически отправляет уведомление пользователю.

### 2. Функции продукта

Сервис должен обеспечивать следующую функциональность:

1. **Обработка сообщений Telegram.** Получение текстовых сообщений пользователей через Telegram Bot API.
2. **Интеграция с LLM.** Использование локальной языковой модели (например Qwen3) через Ollama и Spring AI для анализа запросов на естественном языке.
3. **Создание напоминаний.** Автоматическое определение текста, даты и времени напоминания с использованием механизма Tool Calling.
4. **Хранение данных.** Сохранение напоминаний, идентификаторов Telegram-чатов и статусов отправки в базе данных H2.
5. **Автоматическая отправка.** Периодическая проверка запланированных напоминаний и отправка уведомлений при наступлении заданного времени.
6. **Администрирование.** Просмотр активных напоминаний и возможность их принудительной отправки через веб-интерфейс.
7. **Обработка ошибок.** Проверка корректности данных, обработка ошибок взаимодействия с Telegram API и LLM.

Все даты и время напоминаний обрабатываются в часовом поясе `Europe/Moscow` (МСК).

### 3. Описание интерфейса пользователя

Сервис предусматривает два интерфейса взаимодействия.

#### 3.1. Telegram-бот

Основной пользовательский интерфейс реализуется через Telegram.

Пользователь отправляет текстовое сообщение с просьбой создать напоминание. Сервис анализирует запрос и при успешном создании подтверждает сохранение напоминания.

При наступлении запланированного времени бот автоматически отправляет сообщение с текстом напоминания.

Также допускается обычное текстовое взаимодействие с языковой моделью, не приводящее к созданию напоминаний.

#### 3.2. Веб-панель администратора

Веб-интерфейс доступен по адресу:

`http://{serrbice_base_url}/admin`

Панель администратора представляет собой HTML-страницу с таблицей активных напоминаний.

Для каждого напоминания отображаются:

- Уникальный идентификатор.
- Имя пользователя Telegram.
- Текст напоминания.
- Запланированные дата и время отправки.
- Кнопка принудительной отправки.

Дополнительно предусмотрена кнопка обновления списка напоминаний.

Веб-интерфейс реализуется с использованием HTML, CSS, JavaScript и Thymeleaf.

### 4. Требования к программным интерфейсам

Сервис предоставляет HTTP REST API для взаимодействия с административной панелью.

#### 4.1. Получение активных напоминаний

**GET `/api/reminders`**

Назначение: получение списка напоминаний со статусом `PENDING`, отсортированных по запланированному времени отправки.

Входные параметры отсутствуют.

Пример ответа (`200 OK`):

```json
[
  {
    "id": 1,
    "chatId": 123456789,
    "username": "student",
    "message": "Сдать лабораторную работу",
    "remindAt": "2026-10-16T15:00:00",
    "status": "PENDING"
  }
]
```

Если активных напоминаний нет, возвращается пустой массив `[]`.

#### 4.2. Принудительная отправка напоминания

**POST `/api/reminders/{id}/send`**

Назначение: немедленная отправка выбранного напоминания через Telegram Bot API независимо от запланированного времени.

Входные параметры:

- `id` — числовой идентификатор напоминания в URL.

Тело запроса отсутствует.

Возможные HTTP-статусы:

| Код | Описание |
|---|---|
| 204 | Напоминание успешно отправлено |
| 404 | Напоминание не найдено |
| 409 | Напоминание уже отправлено |
| 502 | Ошибка взаимодействия с Telegram API |

После успешной отправки статус напоминания изменяется с `PENDING` на `SENT`.

#### 4.3. Внешние интеграции

**Telegram Bot API** используется для получения пользовательских сообщений и отправки уведомлений. Получение сообщений осуществляется посредством Long Polling.

**Ollama HTTP API** используется для взаимодействия с локальной языковой моделью. Интеграция реализуется через Spring AI.

Локальный сервер Ollama по умолчанию доступен по адресу `http://localhost:11434`.

### 5. Оценка предполагаемой нагрузки и масштабирование

Сервис разрабатывается как учебное приложение, рассчитанное на небольшое количество пользователей.

Предполагаемая нагрузка:

- До 30 активных пользователей.
- До 1000 сохранённых напоминаний.
- До нескольких запросов к языковой модели в минуту.
- Проверка запланированных напоминаний каждые 10 секунд.

При увеличении нагрузки предусматриваются следующие варианты масштабирования:

1. **База данных:** переход с H2 на PostgreSQL для поддержки большего количества записей и конкурентных операций.
2. **Обработка запросов:** использование асинхронной обработки сообщений и отдельного пула потоков.
3. **Языковая модель:** использование более производительного оборудования или выделенного сервера для Ollama.

Для предполагаемой учебной нагрузки достаточно одного экземпляра Spring Boot приложения.

---

**Итог:** результатом проекта должен стать сервис управления напоминаниями с интеллектуальной обработкой пользовательских сообщений, автоматической отправкой уведомлений, постоянным хранением данных и веб-интерфейсом администрирования.
